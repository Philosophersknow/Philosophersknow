# AIIPD Civic Intelligence™ — Content Architecture Repository

This repository contains the complete content system for the repositioning of AIIPD from a Council Benchmarking System to AIIPD Civic Intelligence™ — a Civic Intelligence and Place Intelligence Platform.

---

## STRATEGIC POSITIONING CONTEXT

**The core repositioning:** AIIPD transforms fragmented information into evidence-based Place Intelligence. Benchmarking is one capability within the intelligence system, not the platform's identity.

**Primary value proposition:** AIIPD Civic Intelligence™ is an intelligence platform — not a benchmarking, ranking, or compliance tool. It synthesises annual reports, budgets, strategic plans, infrastructure data, community consultation, demographic records, and governance documents into structured, evidence-based intelligence for government, policy, and advisory professionals.

**The DRMC framework:** All intelligence is powered by the Dynamic Relational Model of Consciousness (DRMC) — AIIPD's proprietary analytical framework. Reference as the underlying framework; it is not the primary brand.

**Language rules (non-negotiable):**
- REDUCE: benchmarking, performance measurement, scorecards, ratings, rankings, compliance, dashboards, metrics
- INCREASE: intelligence, evidence, insight, place, understanding, decision support, strategic foresight, governance intelligence, community intelligence, emerging risks, opportunities, comparative learning

## FILE-BY-FILE SUMMARY

### Website Content

**homepage.md**
The AIIPD Civic Intelligence homepage content guide. Covers all six page sections (Hero, Platform Overview, Core Capabilities, Target Audiences, Intelligence Database, Call to Action). Full platform description page. Covers six sections: What AIIPD Is, How the Intelligence Engine Works, The Place Intelligence Database, Data Integration, The DRMC Framework, and Security and Governance. Same six-point format as homepage.

**for-consultants-and-researchers.md**
Audience-specific page for Management Consultants, Academic Researchers, and Community Organisations. Covers: headline positioning, research acceleration, evidence synthesis, place intelligence access, community organisations section, and access tier options.

## HOW TO USE THIS REPOSITORY

### For Website and Marketing Content
1. Begin with the style-guide.md — understand the language rules before writing or editing any content
2. Use the relevant audience page as the basis for audience-specific web pages
3. Value-proposition-library.md provides ready-to-use language for specific contexts
4. competitive-differentiation.md supports sales and proposal content

### For Platform UI Development
1. dashboard-language-guide.md is the primary reference for all UI terminology
2. onboarding-ui-copy.md provides every piece of copy for the onboarding flow
3. All UI copy should be reviewed against the style-guide.md terms-to-avoid list before implementation

### For AI Feature Development
1. system-prompts.md provides the system prompt for every AI feature — these are production-ready
2. ai-response-templates.md provides the tone and structure benchmark for AI responses
3. All AI outputs should be reviewed against the style-guide.md language rules

### For Report and Intelligence Product Development
1. report-types-and-templates.md defines the structure, audience, and scope for every intelligence product
2. report-executive-summaries.md provides ready-to-adapt executive summary language for each report type
3. Apply the style-guide.md voice and tone standards to all intelligence content

### For Proposals and Sales
1. value-proposition-library.md provides ready-to-use propositions for different contexts
2. competitive-differentiation.md supports competitive positioning in sales conversations
3. pricing-and-tiers.md provides tier descriptions for proposals and sales materials
4. audience-specific pages provide the intelligence for audience-specific proposals
