# AIIPD Civic Intelligence™ — Dashboard Language Transformation Guide

**Purpose:** Complete term-by-term transformation guide for every UI element in the AIIPD platform. Each entry follows the format: OLD TERM → NEW TERM → REASON → VISUAL TREATMENT → UX NOTE.

**Application:** Apply consistently across all UI elements, tooltips, help text, notification copy, error messages, and interface labels.

---

## PART 1: NAVIGATION LABELS

| # | OLD TERM | NEW TERM | REASON | VISUAL TREATMENT | UX NOTE |
|---|----------|----------|--------|-----------------|---------|
| 1 | Dashboard | Civic Intelligence Centre | "Dashboard" implies passive display. "Civic Intelligence Centre" communicates active intelligence generation and positions the main interface as a strategic capability, not a metrics screen. | Centre-weight layout with intelligence stream summary. Use "CIC" as abbreviated label in collapsed navigation. | Show a brief orientation tooltip on first visit explaining that the Civic Intelligence Centre is the user's primary intelligence workspace. |
| 2 | Reports | Intelligence Briefs | "Reports" implies static documents. "Intelligence Briefs" communicates analytical outputs that are live, purposeful, and audience-tailored. | Document icon with intelligence badge. Differentiate brief types with colour coding by intelligence domain. | Add a "Generate New Brief" shortcut button in the navigation rather than burying it inside the section. |
| 3 | Benchmarks | Comparative Intelligence | "Benchmarks" implies ranking and competition. "Comparative Intelligence" implies contextual learning and peer insight — the same data, more constructive framing. | Side-by-side comparison card interface rather than a ranked list. | Allow users to define their own comparator group by selecting peer organisations — giving them agency over the comparison rather than using a default peer set. |
| 4 | Performance | Organisational Intelligence | "Performance" carries evaluation and judgment connotations. "Organisational Intelligence" frames the same data as internal understanding and improvement. | Intelligence domain cards rather than a performance gauge or score. | Replace single performance score with multi-dimensional intelligence summary showing different aspects of organisational intelligence. |
| 5 | Analytics | Intelligence Analysis | "Analytics" is generic software language. "Intelligence Analysis" aligns with the platform's identity and the analytical depth being applied. | Analysis workflow interface with clear data-to-insight progression. | Add "Analysis in progress" state for asynchronous intelligence generation rather than instant loading spinners. |
| 6 | Data | Evidence | "Data" is a technical term that positions AIIPD as a data tool. "Evidence" communicates the interpretive and analytical value that has been applied. | Evidence cards with source attribution visible. | Show evidence source attribution by default — not hidden behind a tooltip — to build user trust in the intelligence quality. |
| 7 | Metrics | Intelligence Dimensions | "Metrics" implies quantitative measurement only. "Intelligence Dimensions" communicates that AIIPD captures qualitative, contextual, and analytical dimensions alongside quantitative data. | Dimensional spider/radar chart rather than a metrics scoreboard. | Allow users to select which intelligence dimensions are most relevant to their current work, customising their view. |
| 8 | Settings | Platform Preferences | "Settings" is generic. "Platform Preferences" is more descriptive and less technical. | Preference categories with clear groupings: Intelligence Focus, Access and Team, Notifications, Display. | Add a "Personalise your intelligence focus" wizard for new users to configure their most relevant intelligence dimensions. |
| 9 | My Account | My Intelligence Profile | Consistent with the intelligence framing across the platform. | Profile card showing user's role, organisation, intelligence focus areas, and recent activity. | Include a "My intelligence history" view showing recent briefs generated, comparisons run, and intelligence saved. |
| 10 | Help | Intelligence Support | Consistent with framing. Support specifically for navigating intelligence outputs is different from generic software help. | Support hub with intelligence guides, video walkthroughs, and a "How to interpret this intelligence" contextual help system. | Contextual help that appears based on the current page — showing relevant interpretation guidance rather than generic FAQs. |
