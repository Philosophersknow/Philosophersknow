## What This Qualification Is

The Certificate III in Information Technology provides foundational IT skills for people entering or working in technical support, help desk, IT operations, and related roles. It is a broad qualification — the large elective component means it can be customised toward specific roles such as hardware support, cloud computing, cybersecurity, programming, or networking.

## Key Legislative and Ethical Framework

### Privacy Act 1988 (Cth) and Australian Privacy Principles
IT workers handle substantial personal information. The Privacy Act and its 13 Australian Privacy Principles (APPs) govern how this information must be handled. Key APPs for IT workers:
- APP 1: Open and transparent management of personal information
- APP 6: Use or disclosure of personal information only for the purpose collected
- APP 11: Security of personal information — reasonable steps to protect from unauthorised access, use, or disclosure

### Cybercrime Act 2001 (Cth)
Unauthorised access to computer systems is a serious criminal offence. IT workers must understand the distinction between their legitimate access and unauthorised access — even within systems they have access to for work purposes, accessing data beyond their authorisation is illegal.

### Intellectual Property Law
Software is protected by intellectual property law (Copyright Act 1968 (Cth)). Key points:
- Software must be properly licensed — using unlicensed software (piracy) is illegal and exposes organisations to significant liability
- Open-source software has its own licensing requirements (GPL, MIT, Apache, etc.) that must be understood and complied with
- Content created using IT tools (images, text, code) may be protected by copyright

### Workplace Ethics in ICT
- Do not access systems, data, or accounts beyond your authorised scope
- Do not disclose client or employer confidential information
- Report security incidents promptly — not disclosing a security breach compounds the harm
- Follow your organisation's acceptable use policies for systems and internet access

## IT Security Fundamentals

### Common Threats
| Threat | Description |
|---|---|
| **Phishing** | Fraudulent emails or messages designed to trick users into revealing credentials or installing malware |
| **Malware** | Software designed to damage, disrupt, or gain unauthorised access — includes viruses, ransomware, spyware, trojans |
| **Social engineering** | Manipulating people into revealing information or taking actions that compromise security — not technical attacks |
| **Ransomware** | Malware that encrypts the victim's files and demands payment for decryption |
| **Data breach** | Unauthorised access to or disclosure of sensitive data |
| **Insider threats** | Threats from within the organisation — employees, contractors with legitimate access |

### Basic Security Controls
- **Strong passwords / passphrase policies:** Minimum length, complexity, regular rotation for privileged accounts
- **Multi-factor authentication (MFA):** Requiring a second factor (SMS code, authenticator app, hardware key) in addition to a password
- **Software updates and patching:** Many security breaches exploit known vulnerabilities that have been patched — keeping systems updated is a basic control
- **Principle of least privilege:** Users and systems should have only the minimum access required for their role
- **Backups:** Regular, tested, offsite or cloud backups are essential for ransomware recovery
- **User education:** The human is often the weakest link — training users to recognise phishing and social engineering is a critical control

## Technical Support Fundamentals

### The Troubleshooting Process

A systematic approach to troubleshooting prevents wasted time and missed causes:

1. **Identify the problem:** Gather information — what is the symptom? When did it start? What changed? Who is affected?
2. **Establish a theory of probable cause:** Based on the information gathered, what is most likely causing the problem?
3. **Test the theory:** Verify the theory — confirm the cause by testing
4. **Establish a plan of action:** Determine the fix
5. **Implement the solution:** Apply the fix
6. **Verify full system functionality:** Confirm the problem is resolved and no new problems were introduced
7. **Document the findings:** Record the problem, cause, and solution for future reference

### Help Desk Communication
Working at a help desk requires both technical skill and communication skill. Users are often frustrated — clear, professional communication is part of the job:
- Acknowledge the user's issue promptly
- Use plain language — avoid jargon with non-technical users
- Keep the user informed of progress
- Confirm the issue is resolved before closing the ticket
- Document clearly for future reference and escalation

## Key ICT Concepts Quick Reference

| Concept | Explanation |
|---|---|
| **Operating system (OS)** | Software that manages hardware and provides services for programs (Windows, macOS, Linux) |
| **IP address** | Numerical label identifying a device on a network (IPv4: 192.168.x.x; IPv6: longer hexadecimal format) |
| **DNS** | Domain Name System — translates human-readable domain names to IP addresses |
| **DHCP** | Dynamic Host Configuration Protocol — automatically assigns IP addresses to devices on a network |
| **VPN** | Virtual Private Network — encrypts traffic and routes it through a secure server; used for remote access and privacy |
| **Firewall** | Security system that monitors and controls incoming/outgoing network traffic based on security rules |
| **Cloud computing** | Delivery of computing services (storage, processing, software) via the internet rather than local hardware |
| **Backup types** | Full (entire system), incremental (changes since last backup), differential (changes since last full backup) |
| **BIOS/UEFI** | Firmware that initialises hardware before the OS loads |
| **RAM / Storage** | RAM (volatile, fast, for active processes); storage (HDD/SSD — persistent, slower, for saved files) |
